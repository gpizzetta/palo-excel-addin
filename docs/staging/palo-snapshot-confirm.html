Snapshot valeurs

Le complement cree une copie du classeur (*_snapshot_*.xlsx), enregistree sous un nouveau nom, puis supprime les formules uniquement dans cette copie.

Le classeur d'origine (celui que vous avez ouvert) ne sera pas modifie, meme si l'enregistrement automatique est active.

Excel Online / client limite : creation automatique d'une copie impossible.

Le Snapshot va remplacer toutes les formules du classeur ouvert par les valeurs affichees.

Si vous devez garder les formules Palo : annulez, faites d'abord Fichier > Enregistrer une copie, puis relancez Snapshot sur cette copie.
